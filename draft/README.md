# Paper drafts

This folder keeps the paper drafts and their build assets in one place.

| File | Purpose |
|---|---|
| `project-overview.html` | Brief visual introduction to the whole project |
| `training_overview.pdf` | Full working draft with the complete project record |
| `training_overview.tex` | Canonical source for the full working draft |
| `aaai27/main.pdf` | Historical concise AAAI/OpenReview draft |
| `aaai27/main.tex` | Historical venue-specific submission source |
| `aaai27/openreview_abstract.txt` | Historical OpenReview abstract text |
| `aaai27/references.bib` | Shared paper bibliography |

LaTeX auxiliary files for the full draft are stored in `build/working/`. The
AAAI folder remains self-contained because its style files, figures, scripts,
and reproducibility material belong to that historical submission workspace.
The project is now venue-agnostic; this folder is not the active paper target
or schedule.

Older generated material is retained in `archive/` for reference; it is not the
current paper source.
